# ゲーム内確認手順（Vic3 TODO 1.0.0）

この環境ではゲームを起動できないため、以下はまだゲーム内で確認していません。上から順に試し、結果とログを共有してください。

## 準備

1. Victoria 3を完全に終了する
2. リポジトリ直下で次を実行する（Python 3.10以上）

   ```powershell
   git pull
   powershell -ExecutionPolicy Bypass -File .\tools\install_mod.ps1 -GameDir "D:\SteamLibrary\steamapps\common\Victoria 3"
   ```

   `-GameDir` を付けると、建物・技術・法律の一覧をインストール済みのゲームから作り直す（付けない場合は同梱の1.14.5の一覧を使う）
3. ランチャーで新しいプレイセットを作り、「Vic3 TODO - Custom Journals」を有効にする
   - **旧「Vic3 TODO Phase 0 Probe」は無効にする**（HUDのファイルを置き換えるため）
4. 新規ゲームを開始する（Ironmanは避ける）

## 確認項目

| # | 操作 | 期待される結果 |
|---|---|---|
| 1 | サイドバーのMap Listの下にあるボタンを押す | 「カスタムジャーナル」ウィンドウが開く |
| 2 | 「＋ 新しいジャーナル」を押す | 名前変更ポップアップが開く。ウィンドウに「文字を入力中」が出る |
| 3 | `日本で家具工場を10レベル建てる` と入力して確定 | ポップアップが閉じ、ジャーナルが一覧に追加されて編集が開く。入力用の会社が消える |
| 4 | 3で取り込まれない場合 | 「この文字で確定」を押すと取り込まれるか |
| 5 | ジャーナル画面を開く | 「カスタムジャーナル」グループに同じタイトルのJournal Entryがある。本文が表示される |
| 6 | 「＋ 条件を追加」→「建物のレベル」→家具工場 | 進捗バー `0 / 5`。「作成時」が現在の国内レベル合計 |
| 7 | ＋小を5回押して目標を10に | `0 / 10`。基準値は変わらない |
| 8 | 家具工場を1レベル建設して完成させる | `1 / 10` に増える |
| 9 | 「行を追加」で2行目を入力 | 2行目が表示される |
| 10 | 条件「技術の研究」で研究済みの技術を選ぶ | 「達成」。未研究なら「未達成」 |
| 11 | 自動完了オンで、条件をすべて満たす | 次の週かウィンドウを開いたときに完了。JEに完了の通知が出る |
| 12 | 完了・失敗タブで「未完了に戻す」 | 進行中に戻り、JEが再びジャーナルに出る |
| 13 | 期限をオン、「期限切れで失敗」をオン、期限を明日にして時間を進める | 失敗になり、JEに失敗の通知が出る |
| 13b | 条件「州の急進派の割合」を「失敗条件」にし、目標値を現在値より低くする | 次の週かウィンドウを開いたときに失敗になる |
| 14 | ジャーナルのピンボタン（ウィンドウとJEの両方） | アウトライナーに出る／消える |
| 15 | セーブ → メインメニュー → ロード | タイトル（日本語）・条件・基準値・期限がすべて残る |
| 16 | ゲームを完全に終了 → 再起動 → 同じセーブをロード | 15と同じ |
| 17 | 削除、完了済みの一括削除 | 確認後に消える。JEも数日以内にジャーナルから消える |

## 不具合があったとき

ゲームを終了したあと、次のフォルダーのログを添付してください。

`Documents\Paradox Interactive\Victoria 3\logs\` の `error.log`、`game.log`、`gui.log`

あわせて、どの番号の手順で何が起きたか（画面写真があれば添付）を書いてください。`error.log` で `vic3_todo` を含む行が手がかりになります。
